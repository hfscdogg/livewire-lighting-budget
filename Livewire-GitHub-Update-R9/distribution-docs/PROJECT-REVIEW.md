# Sales workflow and inference policy

Current policy: R9, November 17, 2026.

## Client choices and estimating decisions

| Topic | Information to retain | Automatic decision or allowance |
| --- | --- | --- |
| Project | Room list, type of work, travel band, desired control experience, new system versus existing | Current $112.50 person-hour rate; two-person travel crew; available network; room work type starts from project type |
| Recessed lighting | Quantity, lighting effect, fixed or adjustable, separate groups where desired | Complete mapped assembly, compatible control family, required keypad, undimmed power for intelligent lights, device counts, installation and aiming labor |
| Lutron system | Desired experience and whether existing equipment is being retained | HomeWorks for Ketra/Rania, wired designer keypads or applicable wired shades; HomeWorks for new projects beyond the configured RadioRA 3 capacity; shared panels, modules, supplies and gateways counted once |
| Undercabinet | Lit footage, separately operated groups and their lengths, gaps between lit sections | Whole reels/channel lengths, controller capacity, power interfaces, connectors, feed cable and pulling labor from the supported product recipe |
| Decorative fixtures | Existing versus new locations, count, desired grouping, exceptional handling | Owner supplies fixtures; removal, hanging, boxes, support, cable and appropriate controls are counted for the selected work |
| Fans | Keep, replace or install new; number; control preference; specialty mounting | Unchecked support carries replacement boxes/braces and installation labor; new locations carry wiring. A motor compatibility question appears only for wall speed control |
| Shades | Approximate dimensions, collection, privacy goal, power preference and visible options | Size-band budget, separate drives for dual layers, shared supplies, applicable control receivers and wiring, survey and installation labor |
| Access | Finished material, reachable attic, permission for access cuts, height, occupancy and visible exceptions | Shared connecting routes use the room access basis. Cable pulling and surface removal use the selected method. No separate shared-route question |
| No extra cuts | Whether the actual required ceiling/wall route has been checked | Only routes used by the current scope need answers. Changing the access choice removes obsolete no-cut requirements; Back and Save remain available |
| D2R remodel fit | Optional recorded ceiling suitability | Unchecked suitability carries a before-ordering estimator note and a complete priced budget. Known incompatibility remains a hold; clearance is never recorded as verified by inference |
| Customer payoff | Review scope and budget; save or print | Complete range of -10% to +15%, design retainer at 4% of the displayed low end, credited toward the project; no addition of the retainer to job price |

The main access page presents the surface, applicable cut permission and attic access, working height and occupancy. Room work-type exceptions and technical wiring settings remain in optional details. Shade mounting questions appear on Conditions. Product-price dependencies appear with the relevant room selection.

## Pricing review

The supplied 10,086-row supplier reference is preserved. Exact catalog prices, historical budgets and comparable allowances have distinct source records.

The four fixed/adjustable Ketra and Rania D2R remodel assemblies use the supplied light module, mount and power-supply prices. Five supplied Ketra S30 decorative trim-only finishes each cost $82.50 with $150 list. A 20% allowance above that reference carries $99 cost and $180 list-equivalent for the selected D2R decorative trim. This is a same-brand cross-family budget comparison, not an exact supplier quote or a physically interchangeable part. Assembly selling price follows the existing company large-material margin rule. Customer scope identifies the trim allowance without exposing supplier costs. The original missing quote remains visible in the component audit.

Previously blank D2R mappings in local drafts receive this completed allowance. Existing nonblank or custom prices are preserved. The supplement release is recorded with the draft. Company price exports preserve source attribution rather than replacing it with a public-price reference.

No demo kit, replacement emitter, collar, lens or retainer is treated as a complete installation assembly. Supported D2 new-construction assemblies and Alisse/Aviena packages use identified complete-assembly selling allowances. Warm-dim tape uses the supported Lumaris tunable-white recipe. Unsupported existing-can conversions still require a compatible assembly. Adjustable Lumaris and unmapped Ketra linear products remain unsupported combinations. Shade side channels, custom top treatments, structural mounting and lift work require their own dimensional or site-specific allowance; a single generic accessory price would not cover their variable scope. The reserved generic linear-lead and legacy QS-power rows are not gaps in the supported Lumaris/Rania recipes or current shared QS supply calculation.

Glass Palladiom uses the supplied $510 complete-package selling basis. All 36 historical shade bands remain intact, with the upper applicable band used for planning unless a matching current quote is supplied. The 6% materials surcharge and tiered shipping/handling remain included.

## Verification and release boundary

The automated suite covers calculation, controller/run limits, access removal and wire-pulling labor, 480 access/permission combinations, 180 mixed scopes, complete catalog scenarios, room copy and save/import behavior, customer-data separation and shared-server authorization. New mixed-estate cases exercise up to 32 rooms with intelligent lighting, wired tape, shades, replacement fans and new decorative locations. Explicitly incompatible ceilings and blocked no-cut routes still prevent a price from being presented as complete.

Actual iPad Safari interaction, camera uploads and PDF pagination remain device-acceptance checks. Task hours remain estimating standards rather than measured production history. Shared deployment, live Google sign-in and backup restoration are separate unverified deployment work. The public Livewire website is separate from this application.

## Interface references

The review follows progressive disclosure for secondary controls and keeps consequential client choices visible. Defaults can reduce input, but should be visible and editable rather than presented as surveyed facts.
